NSPanel Core — panel recovery

  1. Unplug the panel (mains OFF), open it, connect a USB-to-TTL adapter (3.3V): GND→GND, TX→RX, RX→TX.
  2. Put the ESP32 into download mode (hold BOOT, tap RESET).
  3. Use Chrome or Edge on a computer (needs WebSerial). Click install, pick the USB serial port.

After ANY install: release BOOT, power from mains, reset, wait 60 seconds.

Option A — full NSPanel Core (recommended): bootloader + firmware + config, all 0.1.180 on ESP-IDF 5.5.

Everything ours, bootloader included — app and bootloader are now the same toolchain generation (the old mismatch was the fault). If it boots: setup AP NSPanelCore appears — configure WiFi + MQTT at http://192.168.1.1.

Option B — hybrid fallback: upstream's proven bootloader + our 0.1.180 firmware + clean config.

Use if Option A shows any bootloader trouble. Same firmware, borrowed bootloader.

Option C — upstream NSPanel Manager (last resort): the stock image.

Panel runs upstream software with its own setup flow.
