NSPanel Core — panel recovery

  1. Unplug the panel (mains OFF), open it, connect a USB-to-TTL adapter (3.3V): GND→GND, TX→RX, RX→TX.
  2. Put the ESP32 into download mode (hold BOOT, tap RESET).
  3. Use Chrome or Edge on a computer (needs WebSerial). Click install, pick the USB serial port.
Option 2 (try FIRST — surgical): writes only the app and the config filesystem. The chip's own bootloader and partition table are left untouched.

Firmware 0.1.178 with the panel's own config preloaded (hostname NSPMPanel-49A100, WiFi IoT, MQTT 192.168.50.20).

Option 1 (full — our bootloader too): writes bootloader, partition table, firmware 0.1.178 and the config filesystem. Erases the whole chip first.

Option 3 (full — upstream NSPanel Manager, for comparison): the stock upstream image (bootloader, partition table, app 0.3.967, stock data file). Use this if Option 1 fails but you want to test whether the panel hardware boots upstream.

After this one the panel runs upstream NSPanel Manager — its own setup flow (AP + web page) applies, not ours.

After ANY install: release BOOT, power from mains, reset, wait 60s. Then check your WiFi list for the panel's AP, and your router for the panel.
