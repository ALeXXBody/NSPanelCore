NSPanel Core — panel recovery

  1. Unplug the panel (mains OFF), open it, connect a USB-to-TTL adapter (3.3V): GND→GND, TX→RX, RX→TX.
  2. Put the ESP32 into download mode (hold BOOT, tap RESET).
  3. Use Chrome or Edge on a computer (needs WebSerial). Click install, pick the USB serial port.

After ANY install: release BOOT, power from mains, reset, wait 60 seconds.

Option A — hybrid (recommended first): the bootloader proven to boot this panel + our firmware 0.1.179 + a clean config filesystem.

If it boots: panel appears as setup AP NSPanelCore — open http://192.168.1.1 and configure WiFi + MQTT.

Option B — upstream NSPanel Manager (proven full image): the stock image this panel demonstrably boots.

Panel runs upstream software with its own setup flow.

Option C — surgical (our app only, keeps current bootloader): writes only our app + config filesystem, no erase.

Only useful after Option A has proven the bootloader works.
